AP Biology Review Missions

One review page per unit. In each mission you work a model, make a prediction, test it, then answer exam-style checks. Each unit ends with an Exam Check.

Before you start

  • Open these pages in Safari or Chrome. If this page opened inside the school app, use the app’s ⋯ or Share menu and choose Open in Safari or Open in browser.
  • Your progress is saved in this browser on this device. Use the same device and browser each time, and do not use a private window.
  • Back up at the end of each session. On the unit’s home screen, under My results, tap Back up my progress, then copy the code or save the file.
  • To keep a shortcut, use a bookmark. If you use Add to Home Screen on an iPad or iPhone, turn off Open as Web App. A Home Screen web app keeps its own progress, separate from Safari.

Already started in a downloaded copy?

Progress in a downloaded file does not appear here automatically. Open your old copy and look under My results for Back up or restore. Make a backup there, then open the same unit here, tap Back up or restore, and restore it.

If your copy has no backup button, it is an older version and its progress cannot be moved. Ask your teacher.
